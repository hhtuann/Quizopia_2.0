# Quizopia frontend

Minimal Next.js 16 / React 19 development scaffold using pnpm, strict
TypeScript, Tailwind CSS 4, and the agreed testing/tooling baseline.

Commands:

- `pnpm install`
- `pnpm dev`
- `pnpm lint`
- `pnpm format:check`
- `pnpm typecheck`
- `pnpm test`
- `pnpm test:e2e`
- `pnpm build`

Only the technical landing page exists. Business route groups, API clients,
forms, stores, and feature modules will be added with accepted contracts.
